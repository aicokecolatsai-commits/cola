找出 LINE 技能 — 清單

- LINE Messaging API：傳送/回覆訊息、推播 (Push)、多播 (Multicast)、Broadcast。
- Webhook 事件：message、follow、unfollow、join、leave、postback、beacon、accountLink、memberJoined 等。
- Flex Message：高度客製化的訊息版面與版型。
- Template Messages：Buttons、Confirm、Carousel 等預設樣板。
- Rich Menu：自訂快速選單，可依使用者切換。
- LIFF (LINE Front-end Framework)：嵌入式網頁應用，可結合 LINE Login 與前端功能。
- LINE Login：用戶驗證、取得基本資料與授權。
- Stickers：貼圖訊息與貼圖發送 API。
- Rich Media：圖片、影片、音訊、位置訊息的傳送。
- LINE Beacon / LINE Things：與實體裝置、近場偵測及 IoT 整合。
- LINE Pay：支付與交易整合功能。
- QR Code / Deep Link：快速加入、行銷導流與自動觸發動作。
- Audience & Targeting：分眾目標推播、受眾管理 (Audience Group)。
- Account Linking：帳號綁定以整合外部系統身分。
- Channel Access Token 與權限管理：管理頻道權限與機器人存取。
- 訊息類型與傳送方式：reply、push、multicast、broadcast 的使用情境與限制。

說明：以上為常見可用於開發 LINE 機器人或官方帳號的主要技能與功能項目，可依專案需求取用與整合。
